# GreenTech enhancement — November 2026

This change set fixes the audit findings that could be fixed safely without running
the app, adds unique artwork for every image frame, publishes 25 full articles, and
improves SEO / AEO / GEO. It was written **without node_modules or network access**,
so nothing here has been built, type-checked or run yet. Follow "Run after pulling".

## Run after pulling

```bash
# Backend
cd Backend
npm ci
npm run typecheck          # must be clean
npm test
npm run db:migrate         # applies 0006_rate_limit_bucket
npm run content:seed-blog  # publishes/updates the 25 articles
npm run content:sync-media # points CMS rows at the new artwork + adds service FAQs

# Frontend
cd ../Frontend
npm install                # once: adds motion + lenis to package-lock.json — commit the lockfile
                           # (the VPS uses npm ci, which fails until the lockfile is committed)
npm run typecheck          # fix every error, then remove ignoreBuildErrors in next.config.ts
npm run lint
npm run build
```

On the VPS use the script from the repo so it can load its helper file:
`bash /var/www/greentechagency/deploy/hostinger-greentech.sh update`
SSL now needs an email: `CERTBOT_EMAIL=you@example.com bash deploy/hostinger-greentech.sh ssl`.

## Round 2 (same day)

### File size (300-line rule)
- 72 dead files removed (old portal-kit pages, unused helpers, i18n leftovers), found by an
  import-graph scan from every `app/` entry point. The duplicate `admin-employee-ui-kit/` is gone.
- Every remaining source file is ≤ 300 lines. Large components were split mechanically with the
  TypeScript compiler API: `<Name>.tsx` renders, `<Name>Model.tsx` holds a `use<Name>()` hook with all
  state/handlers (types inferred via `ReturnType`), `<Name>Sections.tsx` holds self-contained JSX blocks.
  Long helper/type modules moved declarations into `*Part.ts(x)` files with re-exports, so imports
  elsewhere did not change. Long CSS modules now `@import` ordered `*.part.css` files (existing repo pattern).
- Checked with: TS syntax on all 554 files, a cross-file semantic pass (missing exports/names, duplicate
  identifiers) = 0 issues, and an unresolved-import scan = 0. A full `tsc` still needs node_modules.

### Fonts
- Only the three weights in use ship, converted to WOFF (~33 KB each instead of ~76 KB TTF).
- Licensed font files are no longer tracked (`.gitignore`); duplicates, `TWKLausannePan-800.otf` and zips removed.
  Keep `Frontend/src/styles/fonts/*.woff` locally; on the VPS upload them once to
  `/var/www/greentechagency-private/fonts/` — the deploy script copies them in before building.
- Old commits still contain the fonts. To purge them: `git filter-repo --path-glob '*.ttf' --path-glob '*.otf' --invert-paths`
  then force-push (rewrites history — coordinate with anyone else using the repo), or make the repo private.

### Performance and security
- Hero video 18.5 MB → 2.7 MB (1280p, 24 fps, no audio, faststart). It loads only after hydration on screens
  ≥ 768 px, never on phones, Save-Data or reduced motion; the poster is the high-priority LCP image.
- Footer CTA artwork 2.1 MB → 212 KB.
- Content-Security-Policy header (YouTube/Vimeo frames allowed; `'unsafe-eval'` only in development).

### Motion
- `motion` and `lenis` added. `shared/motion/`: Lenis smooth scroll synced to the GSAP ticker, a decorative
  follow-ring cursor (fine pointers only, labels via `data-cursor`), GSAP SplitText word reveals on every
  section heading and on article/legal titles, Motion scroll reveals, a magnetic CTA and a spotlight card
  (patterns in the style of Emerald UI / OriginKit / 21st.dev, written from scratch for this repo).
- Everything is disabled for `prefers-reduced-motion`; portals (admin/employee) are untouched.
