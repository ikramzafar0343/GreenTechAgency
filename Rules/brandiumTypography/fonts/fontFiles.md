# Expected font files

This directory contains loading instructions, not the commercial font files.

Add your project's licensed normal WOFF2 faces using the following basenames:

- `twkLausanne250.woff2`
- `twkLausanne300.woff2`
- `twkLausanne400.woff2`
- `twkLausanne500.woff2`

Use `public/fonts/twkLausanne/` for the CSS route, or `src/assets/fonts/twkLausanne/` for the documented Next.js route. Do not leave fonts inside an unextracted ZIP.

The expected names identify real required assets, not zero-byte placeholders. No dummy font files are included. See `../fontSetup.md` for complete setup instructions.
