# Brandium logo assets

25 original transparent PNG files from the Family and Brands section at https://www.brandium.nl/, inspected 6 October 2026. Each download was validated as an image and preserved byte-for-byte. The manifest records the original URL and SHA-256 checksum.

The reference uses approximately 96 CSS pixels of image width. The smallest native files are 270 pixels wide, supporting that display size at 2× pixel density. For strict 3× rendering, use at most 90 CSS pixels for those smaller images. Larger display sizes require a genuinely larger or vector source; these files have not been artificially upscaled or traced.

Copy the logos into your own asset directory, preserve their proportions and transparent padding, and add intrinsic width/height attributes. Source URLs are provenance, not a recommendation to hotlink.

These are Brandium reference assets, not evidence of a relationship with your business. Only present brands as clients or partners when that is true. No fonts are included.

## Included files

- `brandium-logos-design.md`: complete recreation guide.
- `logos/`: 25 PNGs.
- `manifest.json` and `manifest.csv`: source URLs, dimensions, checksums, and size guidance.
- `row-order.json`: both original logo orders, before repetition. Each row repeats the same group three times for continuous movement.
